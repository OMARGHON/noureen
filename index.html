Functions in C
Call by Value – تعريف الدوال واستدعاؤها
📖 ما هي الـ Function؟

الـ Function هي كتلة كود مستقلة بتعمل مهمة معينة، وممكن تنادي عليها من أي مكان في البرنامج.

🧠 تخيّل الـ function زي ماكينة: بتديها مواد خام (parameters) → بتشتغل → بتديك ناتج (return value). مثلاً: ماكينة عصير بتاخد فاكهة وبترجع عصير!
  • كل برنامج C لازم يكون فيه main() على الأقل — ده باب الدخول للبرنامج.
  • الـ Functions بتساعدك تقسم البرنامج الكبير لأجزاء صغيرة (Divide & Conquer) — سهل تفهمه وتصلحه.
  • بدل ما تكتب نفس الكود أكتر من مرة، تكتبه مرة واحدة وتنادي عليه — ده الـ DRY Principle (Don't Repeat Yourself).
كل function بتتكون من 3 أجزاء:
1️⃣ Prototype (الإعلان) — بتقول للـ compiler "في function هتيجي اسمها كذا وبتاخد كذا وبترجع كذا".
2️⃣ Definition (الكود الحقيقي) — هنا بتكتب الكود اللي الـ function هتشتغله فعلاً.
3️⃣ Call (الاستدعاء) — لما بتنادي على الـ function وتشغّلها.

Value-Returning Function: زي sum أو max — بترجع قيمة للمكان اللي ناداها. الـ return type بيكون int أو float أو char إلخ.
void Function: زي printMessage — بتعمل شغل (زي الطباعة) بس مش بترجع قيمة. الـ return type بيكون void.

⚠️ Call by Value: لما بتنادي على function وبتبعتلها متغير، بيتبعت نسخة منه مش الأصل. يعني لو الـ function غيّرت القيمة، الأصل في main مش هيتغير!
💻 مثال: جمع رقمين
C Language 
#include <stdio.h>

// 1) Function Prototype (الإعلان)
int sum(int, int);

int main() {
    int x, y;
    printf("Enter two integers: ");
    scanf("%d %d", &x, &y);

    // 2) Function Call (الاستدعاء)
    int result = sum(x, y);
    printf("Sum = %d\n", result);
    return 0;
}

// 3) Function Definition (الكود الحقيقي)
int sum(int a, int b) {
    int s = a + b;
    return s;
}

ده الـ Prototype — بنقول للـ compiler: "في function اسمها sum، بتاخد رقمين int، وبترجع int". لازم تنتهي بـ semicolon (;) وممكن تحذف أسماء الـ parameters وتسيب النوع بس.

ده الـ Function Call — بنبعت قيمتي x و y للـ sum (اتنسخوا في a و b). الـ function بتشتغل وبترجع الناتج، وبنحطه في result. ملاحظة: x و y نفسهم مش بيتغيروا!
18int sum(int a, int b)
ده الـ Definition — a و b هم الـ Parameters (نسخ من x و y). الـ return type int يعني الـ function لازم ترجع رقم صحيح. اسم الـ function (sum) بيكون في الـ prototype والـ definition نفس بالظبط.
20return s;
بنرجع ناتج الجمع للمكان اللي استدعانا منه (يعني لـ result في main). بعد الـ return، الـ function بتوقف فوراً ومش بتنفذ أي كود بعده.

لو function مش بترجع قيمة، الـ return type بيكون إيه؟

Pass by Reference
تمرير العنوان بدل القيمة باستخدام Pointers
📖 الفرق بين Pass by Value و Pass by Reference

Pass by Value: بيبعت نسخة من القيمة للـ function. التغييرات داخل الـ function مش بتأثر على المتغير الأصلي.

Pass by Reference: بيبعت عنوان المتغير باستخدام pointer. الـ function تقدر تغير القيمة الأصلية.

📦 تخيل الفرق كده:
Pass by Value = بتعمل Photocopy للورقة وبتديها لحد — لو غيّر فيها، الأصل عندك سليم.
Pass by Reference = بتديه الورقة الأصلية — لو غيّر فيها، انت كمان هتشوف التغيير!
⭐ متى نستخدم Pass by Reference؟
✅ لما محتاجين الـ function "ترجع" أكتر من قيمة واحدة (زي area و circumference مع بعض).
✅ لما محتاجين الـ function تعدّل في متغيرات الـ main مباشرة (زي Swap).
❌ لو بس محتاجين نقرأ القيمة ومش هنغيرها — Value أحسن وأبسط.
  • بنبعت العنوان باستخدام & في الـ call — مثلاً: swap(&a, &b)
  • الـ function بتاخد pointer (*) في الـ parameters — مثلاً: void swap(int *a, int *b)
  • للوصول للقيمة جوا الـ function بنستخدم * (dereference) — مثلاً: *a = 10; بيغيّر الأصل
💻 مثال: swap الأرقام
C Language
#include <stdio.h>

void swap(int *a, int *b) {
    int temp;
    temp = *a;      // اقرأ قيمة a
    *a   = *b;      // اكتب قيمة b في a
    *b   = temp;   // اكتب القيمة القديمة لـa في b
}

int main() {
    int a = 3, b = 5;
    printf("Before: %d %d\n", a, b);
    swap(&a, &b);   // بنبعت العنوان مش القيمة
    printf("After:  %d %d\n", a, b);
    return 0;
}
🔍 شرح سطر بسطر
3void swap(int *a, int *b)
الـ function بتاخد pointers مش قيم عادية — يعني عناوين المتغيرات. int *a يعني a هو pointer بيشاور على int. الـ void يعني مش بترجع قيمة.
5temp = *a;
الـ * هنا معناها "اقرأ القيمة الموجودة في العنوان ده" (Dereference). بنحفظ قيمة a الأصلية في temp عشان منخسرهاش في الخطوة الجاية.
6*a = *b;
بنكتب قيمة b في المكان اللي بيشاور عليه a — يعني بنغيّر قيمة a الأصلية في main. دلوقتي a = القيمة القديمة لـ b.
7*b = temp;
بنحط القيمة القديمة لـ a (اللي حفظناها في temp) في b. دلوقتي b = القيمة القديمة لـ a. الـ Swap اتم!
13swap(&a, &b);
الـ & هنا معناها "ابعت عنوان a". مش القيمة نفسها، بعتنا مكانها في الميموري. ده اللي بيخلي الـ swap تأثر على الأصل!
🧠 سؤال اختر الإجابة الصح
📌 في الـ Pass by Value، الـ function بتاخد نسخة من المتغير — يعني تغيير النسخة مش بيأثر على الأصل في main. مثال: لو عندك int a=3, b=5; وعملت badswap(a,b) بدون &، الـ function هتعدّل في نسخ محلية بتتمسح بعد ما الـ function تخلص. الأصل في main مش هيتغير خالص!
لو عملنا badswap(a, b) بدل swap(&a, &b) ، إيه اللي هيحصل؟
أ هتتبدل القيم في main
ب القيم هتتبدل جوا الـ function بس مش في main
ج هيحصل compile error
د البرنامج هيوقف
📌 لما بتعمل int *ptr = &x;، الـ ptr بيخزن عنوان المتغير x في الميموري. عشان توصل للقيمة الموجودة في العنوان ده، بتستخدم * قبل اسم الـ pointer — ده اسمه Dereference. يعني *ptr بتقرأ القيمة الموجودة في المكان اللي ptr بيشاور عليه. ولو كتبت *ptr = 10 — بتعدّل في الأصل مباشرة!
إيه معنى *ptr في سطر الكود؟
أ ضرب ptr في شيء
ب اقرأ أو اكتب القيمة في العنوان اللي ptr بيشاور عليه
ج عنوان ptr نفسه
د pointer جديد

Week 8 – Part 2
Dynamic Memory Allocation
malloc() و free() — الـ Heap memory
📖 ليه محتاجين Dynamic Memory؟

لما بتعمل array عادية، لازم تحدد حجمها وقت الكتابة — زي int arr[10];. لكن إيه لو مش عارف الحجم غير وقت تشغيل البرنامج؟

🎯 مثال حقيقي: برنامج بيطلب من اليوزر يدخل عدد الطلاب، وبعدين يدخل درجاتهم. مش ممكن تعمل array بحجم ثابت — محتاج Dynamic Memory عشان تحجز الحجم اللي اليوزر طلبه وقت التشغيل!
  • Stack Memory: بيتحجز تلقائياً لما function تتنادي (متغيرات عادية، arrays محددة الحجم) — وبيتمسح تلقائياً لما الـ function تخلص. صغير ومحدود.
  • Heap Memory: مساحة أكبر بكتير — بتحجزها إنت يدوياً بـ malloc() وبتمسحها إنت بـ free(). بتفضل موجودة لحد ما إنت تمسحها.
malloc(size) → بتحجز size بايت في الـ Heap وبترجع pointer للأول. لو فشل بيرجع NULL.
free(ptr) → بيرجع الـ memory للنظام. من غيرها هتحصل Memory Leak — يعني الميموري بتتحجز ومش بتترجع!
⚠️ Memory Leak خطير! تخيّل برنامج بيشتغل 24 ساعة ومش بيعمل free — الميموري هتخلص شوية شوية والبرنامج هيقع! عشان كده لكل malloc لازم يقابله free.
💻 مثال: إرجاع array من function
C Language
#include <stdio.h>
#include <stdlib.h>

int* makeArray(int size, int x) {
    int* arr = malloc(sizeof(int) * size);
    arr[0] = 5  + x;
    arr[1] = 7  + x;
    arr[2] = 9  + x;
    return arr;
}

int main() {
    int* z = makeArray(3, 10);
    for (int i = 0; i < 3; i++)
        printf("%d\n", z[i]);
    free(z);   // مهم جداً!
    return 0;
}

الـ function بترجع pointer لـ int — يعني عنوان أول عنصر في الـ array اللي اتحجزت في الـ Heap. مش بترجع الـ array نفسها!

🧠 سؤال اختر الإجابة الصح
📌 الـ malloc و free موجودين في الـ <stdlib.h> — اختصار Standard Library. الـ <stdio.h> للـ input/output (printf/scanf)، و <math.h> للعمليات الحسابية (sqrt/pow). لو نسيت تضيف stdlib.h والـ compiler شغّال بدونها، ممكن malloc يشتغل بغلط أو يديك warning لأن الـ compiler مش عارف الـ return type الصح.

Week 10
Recursion
الـ Function اللي بتنادي على نفسها
📖 إيه هي الـ Recursion؟

الـ Recursion هي لما function بتنادي على نفسها. الـ function دي بتتسمى Recursive Function.

🪞 تخيّل إنك واقف بين مرايتين متقابلتين — بتشوف نفسك أتكرر لما نهاية، بس كل مرة أصغر شوية. الـ Recursion نفس الفكرة — الـ function بتشوف نفسها أتكرر، بس بمشكلة أصغر كل مرة!
⛔ كل recursive function لازم يكون فيها Base Case — وهو الشرط اللي لما يتحقق الـ recursion بتوقف. من غيره البرنامج هيفضل يشتغل للأبد ويحصل Stack Overflow (بيوقع البرنامج)!
  • Base Case: الحالة الأبسط اللي بتتحل بدون recursion — ده الـ "وقف" أو "القاع" اللي الـ recursion بتوقف عنده.
  • Recursive Case: الـ function بتنادي على نفسها بـ parameter أصغر أو أبسط — عشان نقرب للـ Base Case.
🧩 طريقة التفكير في Recursion:
1️⃣ الحالة البسيطة (Base) إيه؟ — الـ factorial(1) = 1.
2️⃣ لو مش Base Case، إزاي أجيب الحل من حل أصغر؟ — factorial(n) = n × factorial(n-1).
3️⃣ كل call بتحل جزء وبتسيب الباقي للـ call الجاية — لحد ما نوصل للـ Base Case.
💻 مثال: Factorial
C Language
#include <stdio.h>

int factorial(int n) {
    if (n == 1)            // Base Case
        return 1;
    return n * factorial(n - 1);  // Recursive Case
}

int main() {
    int num;
    printf("Enter a positive integer: ");
    scanf("%d", &num);
    printf("Factorial = %d\n", factorial(num));
    return 0;
}
🔍 شرح سطر بسطر
4if (n == 1) return 1;
ده الـ Base Case. لما n يوصل لـ 1 بنوقف ونرجع 1. من غيره البرنامج هيفضل يعمل factorial(0) ثم factorial(-1) ثم factorial(-2)... للأبد!
6return n * factorial(n-1);
ده الـ Recursive Case. مثلاً لو n=4:
factorial(4) → 4 × factorial(3)
factorial(3) → 3 × factorial(2)
factorial(2) → 2 × factorial(1)
factorial(1) → 1 (Base Case!)
النتيجة: 4×3×2×1 = 24
🧠 سؤال اختر الإجابة الصح
📌 الـ Base Case هو الشرط اللي لما يتحقق، الـ function بترجع قيمة مباشرة من غير ما تنادي على نفسها. من غير الـ Base Case، الـ function هتنادي على نفسها للأبد — كل call بتعمل call جديدة، وكل call بتاخد مساحة في الـ Stack، والـ Stack حجمه محدود. في الآخر الـ Stack هيفضل ويحصل Stack Overflow والبرنامج هيقع فجأة.
لو نسينا الـ Base Case في Recursive Function هيحصل إيه؟
أ البرنامج هيشتغل بشكل عادي
ب هتحصل infinite recursion والبرنامج هيقع
ج الكومبايلر هينبهنا
د الـ function هتتنفذ مرة واحدة بس
📌 الـ Factorial بيتحسب كده: n! = n × (n-1) × (n-2) × ... × 1. فـ factorial(4) = 4 × 3 × 2 × 1. جرب تحسبها خطوة خطوة: 4×3 = 12، ثم 12×2 = 24، ثم 24×1 = 24. ملاحظة: factorial(0) = 1 وده convention رياضي معروف — أما الـ code في المثال Base Case بتاعته عند 1.
ناتج factorial(4) إيه؟
أ 12
ب 16
ج 24
د 8
⌨️ تحدي: اكتب الكود
اكتب recursive function اسمها sumN بتحسب مجموع الأرقام من 1 لـ n.
مثلاً: sumN(5) = 1+2+3+4+5 = 15
💡 تلميح — Recursion
  • كل recursive function محتاجة حاجتين: Base Case (إمتى بتوقف؟) و Recursive Case (إزاي بتنادي نفسها؟).
  • فكّر في أصغر قيمة ممكنة لـ n — إيه المجموع في الحالة دي؟ ده هو الـ Base Case.
  • مجموع من 1 لـ n = n + مجموع من 1 لـ (n-1) — ترجم الجملة دي لكود مباشرة.

Strings in C
مصفوفات الـ char وعمليات الـ string.h
📖 الـ Strings في C

في C مفيش نوع بيانات اسمه String زي Python أو Java. الـ String عبارة عن array من char بتنتهي بـ \0 (null character أو null terminator).

📝 مثال: char str[20] = "Hello";
في الميموري هيبقى فيه: H | e | l | l | o | \0 | ? | ? | ...
الـ \0 مهم جداً — بيقول للـ functions متى تتوقف عن قراءة الـ string. من غيره ممكن تقرأ بيانات غلط!
  • printf/scanf بتستخدم %s للـ strings
  • fgets(str, size, stdin) لقراءة سطر كامل مع مسافات — أحسن من scanf مع strings
  • لازم تضيف #include <string.h> عشان تستخدم عمليات الـ strings

أهم الـ functions في <string.h>:

  • strcpy(s1, s2) → نسخ محتوى s2 في s1 — لازم s1 كبيرة بما يكفي!
  • strlen(s) → بيرجع طول الـ string (عدد الحروف بدون الـ \0)
  • strcmp(s1, s2) → بيرجع 0 لو متساوين، سالب لو s1 أصغر أبجدياً، موجب لو s1 أكبر
  • strcat(s1, s2) → بيلصق s2 في نهاية s1 — تأكد إن s1 فيها مساحة كافية!
⚠️ ليه مش بنستخدم = مع strings؟
لأن الـ string هي array، و= مع arrays بتنسخ الـ pointer (العنوان) مش المحتوى نفسه! دايماً استخدم strcpy لنسخ الـ strings.
💻 مثال: عمليات على الـ Strings
C Language
#include <stdio.h>
#include <string.h>

int main() {
    char s1[100] = "Hello";
    char s2[100] = "World";

    printf("Length: %d\n", strlen(s1));      // 5

    strcat(s1, s2);
    printf("After strcat: %s\n", s1);         // HelloWorld

    int cmp = strcmp(s1, s2);
    if (cmp == 0)   printf("Equal\n");
    else            printf("Not equal\n");

    return 0;
}

لازم تضيفها عشان تستخدم strlen، strcat، strcmp، strcpy. من غيرها الـ compiler مش هيعرف الـ functions دي.

بترجع عدد الحروف في الـ string بدون الـ \0. "Hello" → 5. لو فيه \n في الآخر (من fgets) هيعدّه — اطرح 1 في الحالة دي.

بتلصق s2 في نهاية s1 بدءاً من مكان الـ \0 في s1. بعدها s1 = "HelloWorld". تحذير: تأكد إن s1 فيها مساحة كافية، وإلا هيحصل Buffer Overflow!

بتقارن الـ strings حرف بحرف أبجدياً. لو 0 = متساويين. لو سالب = s1 أصغر أبجدياً. لو موجب = s1 أكبر. ⚠️ مينفعش تستخدم == مع strings!
🧠 سؤال اختر الإجابة الصح
📌 في C، الـ string هي array من char. لما بتكتب char s1[20] = "Hi";، الـ s1 هو في الحقيقة عنوان أول عنصر في الـ array. لو كتبت s1 = s2;، هتنسخ العنوان مش المحتوى — ده compile error أو سلوك غلط. strcpy هي الطريقة الصح عشان تنسخ المحتوى حرف حرف لحد الـ \0.
ليه مش بنستخدم = عشان ننسخ string في تانية؟
أ لأن = بطيء
ب لأن الـ string هي array وبتنسخ العنوان مش المحتوى، لازم strcpy
ج لأن = بيعمل compile error دايماً مع char
د لا فرق، الاتنين بيشتغلوا
📌 الـ strlen بتعد الحروف من الأول لحد ما تلاقي الـ \0 — ومش بتعدّ الـ \0 نفسه. "Cairo" فيها 5 حروف: C-a-i-r-o. لو الـ string اتقرأت بـ fgets، ممكن يكون في \n في الآخر — في الحالة دي strlen هتعده وترجع 6 مثلاً بدل 5، وده ممكن يسبب مشاكل لو محتاج الطول الصح.
ناتج strlen("Cairo") إيه؟

ب 5
ج 4

استخدم fgets و strlen.

  • تنبيه صغير: fgets بتضيف \n في الآخر — اطرح 1 من strlen عشان تطلع الطول الصح.

Week – Structures
Structures in C
تجميع أنواع بيانات مختلفة في نوع واحد
📖 إيه هي الـ Structure؟

الـ struct بيخليك تجمع متغيرات من أنواع مختلفة في نوع بيانات واحد. زي ما بتعمل "template" أو "قالب" لأي كيان في الحياة الحقيقية.

🎓 مثال حقيقي: بدل ما تعمل int id; char name[50]; float gpa; لكل طالب على حدة —
بتعمل struct Student يشمل كل ده في حاجة واحدة منظمة.
زي ما بتعمل جدول في الـ Excel: كل صف هو Student، وكل عمود هو member.
💡 تقدر تعمل array من الـ struct: struct Student class[30]; — ده زي 30 صف في الجدول!
  • الـ struct بيتعرف برا main باستخدام كلمة struct — ده بيعمل نوع بيانات جديد بس مش بيحجز ميموري.
  • ميموري بيتحجز بس لما تعمل variable من النوع ده: struct Student s1;
  • للوصول للـ members بتستخدم النقطة (.) مع variable عادية: s1.gpa = 3.7;
  • أو الـ arrow (→) مع pointer للـ struct: ptr->gpa = 3.7;
  • ⚠️ C مش بتسمح بـ initialization جوا الـ struct definition — يعني مش تكتب int id = 0; جوا الـ struct.
💻 مثال: struct Student
C Language
#include <stdio.h>
#include <string.h>

struct Student {
    char name[50];
    int  id;
    float gpa;
};

int main() {
    struct Student s1;

    strcpy(s1.name, "Ahmed");
    s1.id  = 2024001;
    s1.gpa = 3.7;

    printf("Name: %s\n",  s1.name);
    printf("ID:   %d\n",  s1.id);
    printf("GPA:  %.1f\n", s1.gpa);

    // Pointer to struct
    struct Student *ptr = &s1;
    printf("Via pointer: %s\n", ptr->name);

    return 0;
}
🔍 شرح سطر بسطر
4struct Student { ... };
بنعرف نوع بيانات جديد اسمه Student. ده مجرد "وصفة" أو قالب — مش بيحجز ميموري لحد ما نعمل variable منه. لاحظ الـ semicolon (;) في الآخر — ده مهم!
11struct Student s1;
دلوقتي بيتحجز ميموري. s1 هو variable من نوع Student. الـ compiler هيحجز مساحة لـ char[50] + int + float كلهم مع بعض.
13strcpy(s1.name, "Ahmed");
بنوصل لـ member name في s1 باستخدام النقطة. لازم strcpy مع strings مش = (لأن name هي array). لو كان int أو float، نقدر نستخدم = مباشرة زي السطر اللي بعده.
23ptr->name
لما عندك pointer للـ struct، بتستخدم → بدل النقطة. ده shortcut — ptr->name يساوي بالظبط (*ptr).name. الاتنين صح بس → أسهل وأوضح.
🧠 سؤال اختر الإجابة الصح
📌 في الـ struct، طريقة الوصول للـ members بتتغير حسب نوع المتغير. لو عندك variable عادية من الـ struct، بتستخدم النقطة (.) — مثل s1.gpa. أما لو عندك pointer للـ struct، بتستخدم السهم (→) — مثل p->gpa. تقدر تتذكرها كده: النقطة مع المتغير العادي، والسهم مع الـ pointer — لأن الـ pointer بيشاور عليه من بُعد!
لو عندنا struct Student *p; إيه الطريقة الصح نوصل بيها للـ gpa؟
أ p.gpa
ب p->gpa
ج *p.gpa
د p::gpa
📌 عشان تعمل array من struct، لازم تكتب الـ keyword struct قبل اسم النوع. في C مش زي C++ اللي بتقدر تحذف كلمة struct. الصح هو: struct Student class[10]; — ده بيعمل 10 عناصر من نوع Student، كل عنصر فيه name و id و gpa. للوصول مثلاً للطالب الأول: class[0].name أو class[0].gpa.
إيه الـ syntax الصح لعمل array من 10 students؟
أ Student class[10];
ب struct Student class[10];
ج struct[10] Student class;
د array Student[10];

عرّف struct Product بـ: name (char[50])، price (float)، quantity (int).
اعمل instance منه، حط فيه بيانات، واكتب function بتحسب الـ total value = price × quantity وتطبعها.
💡 تلميح — Structures
  • عرّف الـ struct برا main — فكّر في مثال Student فوق، نفس الشكل بس بـ members مختلفة.
  • لنسخ string جوا struct لازم strcpy مش = — ليه؟ لأن الـ string هي array.
  • الـ function بتاخد الـ struct كـ parameter عادي — الوصول للـ members بيكون بـ النقطة (.)
  • Total value = price مضروب في quantity — ده حساب بسيط جوا الـ function.

📌 الـ function في C بتتكون من: return type ثم اسم الـ function ثم الـ parameters. الـ return type بيحدد نوع القيمة اللي الـ function هترجعها — زي int لو هترجع رقم صحيح، أو float لو كسري، أو void لو مش هترجع حاجة. مثال: int sum(int a, int b) — هنا int الأول هو الـ return type.

أ void
ب return
ج الـ return type (زي int أو float أو void)
د define
📌 في الـ Pass by Value (وده الـ default في C)، لما بتبعت متغير للـ function، بيتبعت نسخة منه. الـ function بتشتغل على النسخة — مش على الأصل. يعني مهما غيّرت جوا الـ function، الأصل في main مش هيتغير. عشان تأثر على الأصل، لازم تبعت العنوان &x وتستخدم Pointer.
2️⃣ لو كتبنا int x = 5; func(x); وجوا func غيّرنا قيمة x — هل قيمة x في main هتتغير؟
أ أيوه دايماً
ب لأ، ده Pass by Value — بيتبعت نسخة
ج بتتغير بس لو int
د بيعمل compile error
📌 للتعامل مع عناوين الميموري في C، عندنا رمزين مهمين: & معناه "خدلي العنوان" — بتستخدمه لما بتبعت متغير للـ function بـ reference: func(&x). و* معناه "اقرأ القيمة في العنوان ده" — بتستخدمه جوا الـ function عشان توصل للقيمة الأصلية: *ptr = 10. ببساطة: & لما بتبعت، * لما بتستقبل وتستخدم.
3️⃣ إيه الرمز اللي بنستخدمه عشان نبعت عنوان متغير لـ function؟
أ *

📌 sizeof(int) بيرجع حجم الـ int بالبايت — عادةً 4 بايت. فـ malloc(sizeof(int) * 5) بتحجز 4×5 = 20 بايت في الـ Heap، وبترجع pointer للأول. الفرق عن الـ Stack: الـ Heap بيفضل محجوز لحد ما تعمل free — مش بيتمسح لما الـ function تخلص. استخدام sizeof أفضل من كتابة 4 مباشرة عشان الكود يشتغل على أي جهاز.
4️⃣ malloc(sizeof(int) * 5) بتعمل إيه بالظبط؟
أ بتعمل array عادية بـ 5 عناصر في الـ Stack
ب بتحجز مساحة لـ 5 integers في الـ Heap وبترجع pointer
ج بتعمل 5 متغيرات منفصلين
د بتحجز 5 bytes بس
📌 الـ Recursive Function بتنادي على نفسها. عشان تتوقف، لازم يكون فيها Base Case — وهو الشرط اللي لما يتحقق، الـ function بترجع قيمة مباشرة من غير ما تنادي على نفسها تاني. كل call جديدة بتضيف frame في الـ Stack. من غير Base Case، الـ Stack هيفضل لحد ما يحصل Stack Overflow والبرنامج يقع فجأة.

أ Loop
ب printf
ج Base Case
د malloc
📌 strlen بتعد الحروف من أول الـ string لحد ما تلاقي \0 — ومش بتعدّ الـ \0 نفسه. "Hello" فيها 5 حروف: H-e-l-l-o. لو فكّرت إن فيها 6 عشان حاسب على الـ \0 في الـ array — ده غلط، strlen مش بتعدّه. حجم الـ array char s[6] يسع "Hello" + الـ \0، بس strlen بترجع 5 مش 6.

📌 لما بتكتب char s1[20] = "Hi";، الـ s1 في الحقيقة عنوان أول خانة في الـ array. لو كتبت s1 = s2، ده بيحاول ينسخ عنوان (مش محتوى) — ومش ممكن أصلاً لأن اسم الـ array مش assignable. الـ strcpy هي الصح: بتمشي حرف حرف وتنسخ كل حرف لحد الـ \0. دايماً تأكد إن الـ destination فيها مساحة كافية!

ج لأن = مش بتشتغل مع char

📌 لما عندك pointer للـ struct — زي struct Car *p = &myCar; — للوصول للـ members عندك طريقتين: الطويلة (*p).speed (الـ () مهمة هنا!) أو الـ shortcut المريح p->speed. الاتنين بيعملوا نفس الشيء بالظبط. قاعدة سهلة: النقطة مع المتغير العادي، والسهم مع الـ pointer.

📌 الـ Heap Memory مش بتتمسح تلقائياً زي الـ Stack. لو حجزت ميموري بـ malloc ونسيت تعمل free، الميموري هتفضل محجوزة طول ما البرنامج شغّال — حتى لو مش بتستخدمها. ده اسمه Memory Leak. لو البرنامج شغّال لفترة طويلة أو بيعمل malloc كتير، الميموري المتاحة هتقل شوية شوية والبرنامج هيبطأ أو يقع. القاعدة الذهبية: لكل malloc يقابله free واحد.
9️⃣ بعد ما نخلص من الـ dynamic memory — إيه اللي لازم نعمله؟
أ مش محتاج نعمل حاجة، بتتمسح لوحدها
ب نعمل realloc
ج نعمل free(ptr) عشان منعملش memory leak
د نعمل malloc تاني
